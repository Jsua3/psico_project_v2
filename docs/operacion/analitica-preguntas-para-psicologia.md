# Analítica de aprendizaje: 16 decisiones que necesitamos de Psicología

> **BORRADOR.** Esta hoja pide decisiones; ninguna cifra es oficial hasta que Psicología responda. El sistema ya calcula todo con la opción marcada con ★ (la que el equipo técnico propuso para poder empezar). Hoy las cifras salen de una consulta del servidor para docentes y administradores: **todavía no hay una pantalla que las muestre**. Por defecto, el índice interno de 1 a 4 no es una nota ni se le muestra al estudiante; las cifras son agregados y no se publican con menos de 5 estudiantes (ver la pregunta 10b).
>
> **Cómo responder:** marque una letra por fila (o escriba la suya en «Otra»). Si la ★ le parece bien, basta con marcarla. El detalle técnico de cada punto está en el documento «analitica-de-aprendizaje», sección 10.
