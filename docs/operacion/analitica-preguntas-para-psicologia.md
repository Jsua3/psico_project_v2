# Analítica de aprendizaje: 16 decisiones que necesitamos de Psicología

> **BORRADOR.** Esta hoja pide decisiones; ninguna cifra es oficial hasta que Psicología responda. El sistema ya calcula todo con la opción marcada con ★ (la que el equipo técnico propuso para poder empezar). Nada de esto es una nota para el estudiante: el índice interno de 1 a 4 solo lo ven docentes y administradores, siempre agregado y nunca con menos de 5 estudiantes.
>
> **Cómo responder:** marque una letra por fila (o escriba la suya en «Otra»). Si la ★ le parece bien, basta con marcarla. Detalle técnico de cada punto: `docs/operacion/analitica-de-aprendizaje.md` §10.
