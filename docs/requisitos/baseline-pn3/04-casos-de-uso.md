# Casos de uso (CU-01 a CU-15)

> Fuente: hoja «CASOS DE USO — VERSIÓN ACADÉMICA INICIAL» de `RequisitosPN3.xlsx` (versión académica inicial, línea base unificada de la carrera). Texto fiel al Excel; si el Excel cambia, este archivo se regenera, no se edita a mano.

| ID | Caso de uso | Actor principal | Objetivo | RF relacionados | Estado |
|---|---|---|---|---|---|
| CU-01 | Iniciar sesión | Todos | Permitir que el usuario ingrese al sistema y acceda a las funciones que correspondan a su rol. | RF-01, RF-02 | Definido |
| CU-02 | Gestionar usuarios | Administrador | Crear usuarios, actualizar sus datos, activar o desactivar cuentas y asignar roles. | RF-03 | Definido |
| CU-03 | Gestionar grupos | Profesor | Crear grupos y agregar estudiantes que ya estén registrados en el sistema. | RF-04 | Definido |
| CU-04 | Crear y configurar caso | Profesor | Construir un caso definiendo sus escenas, personajes, decisiones, opciones, ayudas y retroalimentaciones. | RF-05 a RF-11 | Definido |
| CU-05 | Validar y publicar caso | Profesor / Sistema | Revisar que el caso cumpla las reglas definidas y luego publicarlo, archivarlo o dejarlo como borrador. | RF-12, RF-13 | Definido |
| CU-06 | Asignar caso | Profesor | Asignar un caso publicado a grupos o estudiantes. | RF-14 | Definido |
| CU-07 | Consultar caso habilitado | Estudiante | Ver los casos disponibles y revisar la información inicial antes de comenzar. | RF-15, RF-16 | Definido |
| CU-08 | Ejecutar simulación | Estudiante / Sistema | Recorrer las escenas, tomar decisiones y continuar por la ruta que resulte de las opciones elegidas. | RF-17, RF-21 | Definido |
| CU-09 | Consultar ayuda | Estudiante | Consultar una ayuda o pista disponible durante la simulación. | RF-18 | Definido |
| CU-10 | Guardar y continuar intento | Estudiante / Sistema | Guardar el avance del intento y continuar después desde el último punto registrado. | RF-19 | Definido |
| CU-11 | Registrar bitácora | Estudiante | Escribir y guardar reflexiones o justificaciones durante el intento. | RF-20 | Definido |
| CU-12 | Finalizar y evaluar intento | Estudiante / Sistema | Finalizar el intento cuando se llegue a una conclusión y guardar la valoración formativa correspondiente. | RF-22 | Definido para esta fase |
| CU-13 | Consultar resultados | Estudiante | Consultar al final la retroalimentación, el resultado y el historial de intentos. | RF-23, RF-24 | Definido |
| CU-14 | Revisar desempeño | Profesor | Revisar el recorrido y el desempeño de los estudiantes. | RF-25 | Definido |
| CU-15 | Generar reporte | Profesor | Generar reportes básicos de un estudiante o de un grupo. | RF-26 | Definido |
