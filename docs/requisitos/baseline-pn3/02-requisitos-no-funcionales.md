# Requisitos no funcionales (RNF-01 a RNF-08)

> Fuente: hoja «REQUISITOS NO FUNCIONALES — VERSIÓN ACADÉMICA INICIAL» de `RequisitosPN3.xlsx` (versión académica inicial, línea base unificada de la carrera). Texto fiel al Excel; si el Excel cambia, este archivo se regenera, no se edita a mano.

| ID | Categoría | Nombre | Descripción | Prioridad | Estado |
|---|---|---|---|---|---|
| RNF-01 | Seguridad | Protección de credenciales | Las credenciales de los usuarios deben guardarse de forma segura y no deben quedar almacenadas como texto visible. | Alta | Definido |
| RNF-02 | Seguridad | Comunicación segura | Cuando la plataforma esté desplegada, la información que se envíe entre el usuario y el sistema debe viajar por una conexión segura. | Alta | Definido |
| RNF-03 | Usabilidad | Interfaz adaptable | La interfaz debe poder usarse desde computador, tableta y celular. | Alta | Definido |
| RNF-04 | Accesibilidad | Accesibilidad básica | La interfaz debe facilitar la lectura y el uso, incluyendo navegación con teclado, buen contraste y textos legibles. | Media | Definido |
| RNF-05 | Rendimiento | Respuesta fluida | El sistema debe responder con fluidez cuando el estudiante pase de una escena a otra o tome una decisión. | Alta | Por medir posteriormente |
| RNF-06 | Disponibilidad | Disponibilidad académica | La plataforma debe estar disponible durante las actividades académicas en las que se vaya a utilizar. | Media | Por validar |
| RNF-07 | Mantenibilidad | Separación de componentes | Los componentes principales del sistema, como el DSL, la validación, la simulación, la persistencia y la interfaz, deben mantenerse organizados de forma separada. | Media | Definido |
| RNF-08 | Datos | Integridad de la información | La información de los casos, intentos y resultados debe mantenerse correcta y consistente mientras se usa el sistema. | Alta | Definido |
