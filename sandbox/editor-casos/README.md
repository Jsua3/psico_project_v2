# Sandbox del editor de casos (P3)

Versión de prueba, simplificada, de cada momento que vive el docente al crear un caso. Corre en
tu máquina; no tiene cuentas ni guardado en servidor (el caso se guarda en el navegador).

```bash
cd sandbox/editor-casos
npm install
npm start          # http://localhost:4310
npm test
```

La guía completa de uso y el guion de prueba con un docente llegan en la última tarea del plan.
